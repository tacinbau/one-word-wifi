## The word

**Ghosting** — home Wi-Fi that vanishes mid-call without a word, like a bad date. Funny at once, true to how Wi-Fi actually behaves, and it works as a network name. One word, 8 characters, inside the 1–20 character gate.

## Run

```sh
node main.ts
```

Writes `Ghosting` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
